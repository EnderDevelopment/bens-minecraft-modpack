# Ben's Modpack

Ben's Modpack is a Minecraft plugin designed to enhance the gameplay experience with custom commands and features. This plugin is built using the PaperMC API and is compatible with Minecraft version 1.21. It includes a simple "ciao" command that greets players, making it a great starting point for custom plugin development.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Join your Minecraft server.
2. Use the `/ciao` command to receive a greeting message.
